## AI Portfolio Chatbot

### Overview
Developed a conversational AI chatbot using Blazor and ASP.NET Core Web API. Integrated Azure OpenAI for dynamic, context-aware responses and implemented contextual response generation using structured markdown knowledge sources.

### Key Features
- Conversational AI interface
- Blazor frontend
- ASP.NET Core Web API backend
- Azure OpenAI integration
- Context-aware response generation
- Multi-document knowledge context system
- Server-side conversation history management
- Scrollable real-time chat interface

### Architecture
- Blazor UI layer
- ASP.NET Core API layer
- KnowledgeContextService
- Azure OpenAI integration
- Markdown-based knowledge retrieval

### Technologies
- Blazor
- ASP.NET Core
- C#
- Azure OpenAI
- REST APIs
- JavaScript Interop
